=====================================================
  Simply Speakers - Changelog
=====================================================

-----------------------------------------------------
  Version 0.7.9
-----------------------------------------------------

 Added
  - Server Config Synchronization: Server configs (speaker range,
    upload limits) now automatically synchronize to clients on join
    and restore client-local values upon disconnecting.
  - Overlapping Speaker Audio Blending: Speakers and proxies sharing
    the same ID blend into a single synchronized virtual multi-point
    emitter, eliminating echoes, comb filtering, and volume doubling.

-----------------------------------------------------
  Version 0.7.8
-----------------------------------------------------

 Fixed
  - Looping audio now resumes at the correct position after
    leaving a speaker's range and returning.
  - Short audio clips now continue looping indefinitely
    instead of stopping after only a few repetitions.
  - Fixed an OpenAL buffer cleanup race that caused permanent
    buffer underruns during loop playback.
  - Loop transitions now finish playing all queued audio,
    preventing clipped or shortened repetitions.
