# 0.10.0

- Add **timed entry/exit fade durations (ms)** as local listener settings, defaulting to 250 ms each. These new durations work independently of the existing per-speaker **Distance fade (%)** slider. Set either duration to zero to disable that timed transition.
- Add opt-in stereo playback for MP3/WAV files and HTTP(S) streams, preserving left/right channels with one listener-relative source per linked network. Positional mono remains the default.
- Preserve distance/directional gain, game volume controls, looping and authoritative re-entry position. Keep explicit stop and lifecycle cleanup immediate.
- Distinguish range exits from immediate stops in the playback protocol. Server and clients must update together.

- Redesign the audio-zone preview with a range sphere, distinct direction guides, a north-up listener map and live spatial volume/distance readouts. Extend the preview to 30 seconds and dismiss it when opening a menu.
- Explain ownership and operator overrides consistently with Simply Screens, and add missing settings tooltips for speaker, proxy and redstone-controller forms.

- Move entry/exit fades and stereo into Settings > Your listening settings, add a personal audio-cache budget, and import existing values once. These choices work without speaker control permissions and are no longer mod-config options.
