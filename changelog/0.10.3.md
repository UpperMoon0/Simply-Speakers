# Simply Speakers 0.10.3

- Prevent new-song downloads from enqueueing an entire audio file ahead of gameplay traffic on slow connections.
- Share PacketWeave's connection budgets with other media mods, sending one 4 KiB chunk per transfer before waiting for a receiver write receipt.
- Move downloaded audio writes and cache finalization off the game thread; keep playback and UI changes on the game thread.
- Protect all completed tracks awaiting playback and active decoder files during serialized LRU cache eviction.
- Defer up to 64 distinct audio requests if eight downloads are active and resume them when transfers finish or fail, including server admission rejection.
- Release canceled download slots immediately when leaving a world; retire partial files for asynchronous cleanup and reject stale positive receipts.
- Bind downloads and receipts to unique request IDs and authenticated connections. Bound concurrent work and fail stalled transfers without disconnecting players.
- Require PacketWeave 0.1.5 or newer. Update both client and server together: the media packet format changed. Existing audio libraries and completed caches remain compatible.
