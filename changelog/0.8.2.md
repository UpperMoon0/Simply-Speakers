# Simply Speakers 0.8.2

## Changed

- **Server-Authoritative Emitter Lifetime**: Removed client-side missing-block-entity timeouts and dead position culling. Audio streams now persist seamlessly through client chunk churn, simulation border crossings, and temporary chunk unloading until explicitly stopped by the server.
- **Shared Listener Range Policy**: Extracted `ListenerRangePolicy` to common code with unified `SpatialAudioCalculator.LISTENER_EXIT_HYSTERESIS` margin across all supported loaders, preventing rapid start/stop flutter when lingering near maximum speaker range.
- **Shared Client Playback Membership**: Extracted thread-safe `PlaybackMembership` in common code to manage speaker-to-network associations and preserve cached emitter spatial settings during chunk unloads.
- **Updated OpenUI Requirement**: Upgraded required OpenUI MC dependency to 0.0.7.

## Fixed

- **Chunk Churn Continuity**: Resolved an issue where music stopped playing within audible range after moving across chunk boundaries and would never resume.
- **Proxy Speaker Stop Broadcast**: Fixed `ProxySpeakerBlockEntity.stopAudio()` to broadcast stop packets to all players in the level across all Minecraft versions (1.20.1, 1.21.1, and 26.1.2).
- **Cross-Dimension Audio Cleanup**: Registered client respawn events to cleanly reset OpenAL resources and pending audio requests when transitioning across dimensions, while properly preserving playback on same-dimension respawns.
- **Authoritative Speaker Range Clamping**: Enforced `Config.speakerRange` clamping during client block entity refreshes and unified effective-range evaluation via `SpeakerSettings.effectiveRange()` across all loaders.

## Development

- **Behavioral & Wiring Tests**: Added pure unit test suites for `ListenerRangePolicy` and `PlaybackMembership`, along with cross-version structural wiring tests in `:common:test`.
- **CI Enhancements**: Updated GitHub Actions live-join workflows to include common unit tests and corrected path triggers for the `shared/` directory tree.
