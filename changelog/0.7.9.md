# Simply Speakers 0.7.9

## Added

- **Server configuration synchronization**
  - Speaker range, upload availability, and upload-size limits now synchronize to clients when they join.
  - Config changes made while the server is running are broadcast to connected players.
  - Client-local values are restored after disconnecting from a server or leaving a world.

- **Overlapping speaker audio blending**
  - Main and proxy speakers sharing an ID now use one synchronized virtual multi-point audio source.
  - The virtual source follows a gain-weighted spatial center as the listener moves through overlapping coverage.
  - Prevents echoes, comb filtering, phase cancellation, desynchronization, and volume doubling between linked emitters.

- **Audio caching and streaming improvements**
  - Added bounded client audio caching with access tracking and cleanup.
  - Added incremental MP3 and WAV decoding to reduce playback memory usage.
  - Added stereo and multi-channel downmixing for reliable positional playback.
  - Audio duration is now stored and used for accurate resume, looping, and natural end-of-file handling.

## Changed

- Speaker state is now authoritative on the server and isolated per dimension.
- Linked main speakers now share playback state while retaining independent physical emitters and redstone power.
- Multiple powered main speakers with the same ID can start, stop, unlink, unload, or be removed without incorrectly stopping the remaining network.
- Standalone speakers receive persistent internal IDs, with migration support for worlds created before 0.7.9.
- Listener scans are throttled, track exact configured range, and immediately respect a lowered server range.
- Audio transfers now use per-world workers and cleanly restart when changing worlds or restarting a server.
- State packets can represent network-only updates without using a fake block position.

## Fixed

- Fixed loop changes not reaching active standalone streams or playback waiting on a download.
- Fixed stale speaker selections, loop-button text, and playback state across multiple clients and linked speaker GUIs.
- Fixed linked streams continuing after an authoritative network stop or audio deletion.
- Fixed standalone cached audio continuing after its source audio was deleted.
- Fixed speaker state being lost when its chunk unloaded.
- Fixed relinking or removing one main speaker stopping other powered mains with the same ID.
- Fixed unpowered speakers starting playback when moved between linked networks.
- Fixed valid MP3 uploads being rejected and temporary upload filenames preventing content validation.
- Fixed registry migration, backup, corruption recovery, and generated standalone IDs not persisting reliably.
- Fixed active uploads silently hanging when uploads are disabled during transfer.

## Security and hardening

- Server packet handlers now validate speaker access, distance, values, ownership, and configured limits.
- Audio downloads now require file ownership or a short-lived playback authorization.
- Uploads are streamed to temporary files with concurrency, chunk-size, total-size, timeout, and content validation.
- Audio deletion now clears affected speaker states and synchronizes the authoritative result to clients.
- Transfer requests, playback grants, temporary files, cached files, and worker resources now receive bounded lifecycle cleanup.
