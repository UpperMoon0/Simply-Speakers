# Simply Speakers 0.8.4

The playback-and-control release: Simply Speakers graduates from a sound emitter
into a programmable, synchronized audio system with server-authoritative continuity.

## Added

- **Settings help**: readable names and individual explanations for every redstone mode, hover help on main/proxy settings and save controls, and a cone-angle slider that matches the server limits.

- **Audio Circuit**: a shared crafting component with a generated transparent 16x16 texture. Speakers, proxies, controllers and the guide now require it to reduce recipe clashes; included in the creative tab and guide.

- **Named playlist management**: create, browse, rename, duplicate and delete saved playlists per network. Choose the destination when saving a Library track. Browsing/editing leaves current playback alone; explicit Play switches the source. Existing single lists migrate to Default.

- **Linked Redstone Controller**: one job per block, with inputs accepted from any side. Pulse play/pause, next, previous, stop, restart, or a one-shot announcement; continuous enabled and analog volume controls can target a network or one proxy. Links recheck the configuring player's network rights.
- **Ignore redstone mode**: main speakers can emit without local power when controlled through linked controllers or other transport controls. Existing saved redstone mode ordinals remain compatible.
- **Simply Speakers Guide**: a craftable Patchouli book in the mod creative tab, with 23 chapters covering setup, playback, automation, administration, and integrations. Patchouli is required and included in all five development environments.
- **16×16 artwork**: generated controller face and transparent guide-book inventory texture matching the speaker palette.

- **Playlists & queues**: ordered track lists per speaker network with one-shot
  play-next queue, seeded shuffle, and repeat off/track/playlist modes.
- **Transport controls**: pause/resume that preserves the playback position,
  absolute seek, restart, next/previous track — from the GUI, redstone,
  commands, the new Java API, and CC:Tweaked.
- **CC:Tweaked integration** (optional dependency): every main Speaker is now a
  `simply_speaker` peripheral with `play/pause/togglePause/stop/restart/next/
  previous/seek/setTrack/getStatus/setVolume/getVolume/setRange/getRange/
  setLooping/isLooping/setShuffle/setRepeatMode/queueNext/getPlaylist/
  getNetworkName/setNetworkName`, plus `speaker_started`, `speaker_paused`,
  `speaker_resumed`, `speaker_stopped`, `speaker_track_changed`, and
  `speaker_finished`   events. Available on Fabric
  1.20.1, Forge 1.20.1, Fabric 1.21.1, and NeoForge 1.21.1.
- **Advanced redstone modes**: power (classic), pulse (restart on rising edge),
  toggle (play/pause on rising edge), next (skip on rising edge),
  analog volume (signal 0-15 -> volume), and analog track (rising edge selects
  playlist slot by signal strength).
- **Comparator output**: main speakers emit a redstone comparator signal —
  0 stopped, 1-14 proportional playback progress, 15 finished.
- **Named speaker networks**: give any network a human-friendly name in the GUI;
  inspect it with `/simplyspeakers networks` and `/ss network <name> info`.
- **Audio library organization**: display names, categories, tags, upload
  timestamps and uploader names on every audio entry; edit via commands or the
  library packets, search/filter against all fields.
- **Ownership & access control**: networks can be PUBLIC, TRUSTED, OWNER_ONLY,
  or OPERATORS-only, with trusted-player lists and automatic owner claiming on
  first policy change. Operators always retain control.
- **Directional audio**: directionality, cone angle, and rear attenuation per
  speaker; audio focuses into the cone in front of the block face.
- **Internet streams**: select a direct `http(s)://...mp3/.wav` URL as a track;
  clients stream it live without caching. No yt-dlp, no transcoders.
- **Commands**: `/simplyspeakers` (`/ss`) with `networks`, `network <name>
  info|play|pause|stop|restart|next|previous|seek|volume|range|loop|shuffle|
  repeat|redstone`, `speaker <pos> ...` and `audio list|rename` trees.
- **Java API**: `com.nstut.simplyspeakers.api.SpeakerApi` for other mods/KubeJS
  plus `SpeakerEvents` lifecycle callbacks.

## Changed

- Track selection no longer stops a playing network when the same audio is
  re-selected; transport state is preserved across GUI refreshes.
- Playlist-aware natural end-of-track handling: networks advance to the next
  playlist entry instead of stopping outright.

## Development

- **Patchouli discovery in dev runs**: legacy loader resource tasks expose the shared book definition through the actual mod resource root, while localized contents and textures remain shared.
- **Repeatable 1.20.1 recipes**: recipe conversion reads original resources on every build, preserving result items and the Patchouli book ID across repeated builds.
- **Fabric startup ordering**: ComputerCraft's peripheral lookup is registered after the speaker block entity type exists.

- **New Packet Layer**: TransportControlC2S, PlaylistControlC2S, SpeakerPolicyC2S, UpdateAudioMetaC2S, RequestPlaylistC2S, and PlaylistSyncS2C, registered consistently across all five loader targets.
- **Wire Compatibility**: Directional cone settings ride along in PlayAudioPacketS2C behind an optional trailing block for wire compatibility with 0.8.1+ clients and servers.

## Review Fixes

- **Legacy World Migration Restored**: pre-0.8.x speaker worlds are migrated into the server registry again.
- **Playlist Content Authorization**: playlist operations now authorize the referenced audio content the same way track selection does.
- **Remote Stream EOF Identity & Quorum**: client end-of-stream reports for internet streams are checked for track identity and quorum before the network advances.
- **Live Comparator Output**: comparator signals refresh during playback instead of only on state changes.
- **Resume Position Persistence**: resumeIndex survives restarts so paused networks resume where they left off.
- **CC:Tweaked setTrack**: the advertised `setTrack` peripheral method is now implemented on every loader target.
- **Listener-churn EOF Quorum**: remote URL tracks re-evaluate their EOF quorum when listeners disconnect, leave range, change dimension, or an emitter is removed, so playback can no longer stall forever after a listener churns mid-track.
- **Restart Generation Isolation**: explicit restarts (and re-selecting a track on a playing network) start a new playback session, so delayed EOF reports from the previous run can never end the restarted stream.
- **Seek Hardening**: absolute seeks are rejected on stopped networks and non-finite (NaN/Infinity) values are rejected at the service and state layers.
- **CC:Tweaked setTrack Ownership**: automation is treated as untrusted and acts on behalf of the speaker network's owner; library tracks are selectable only when owned by that owner.

- Restored the OpenUI 0.0.12 player redesign: Library, Playlist, Queue and Settings navigation, per-track menus, persistent transport, draggable seeking and timestamp jumps. Temporary queue requests stay separate from saved playlists.

- Polished player layouts: centered pixel-icon transport with descriptive hover tooltips, aligned time and track durations, safe long-name truncation, and a compact timestamp dialog with inline validation. Proxy settings now scroll at short heights. Native visual audits cover every screen across four sizes and both themes.

- Replaced direct Speaker/Proxy redstone input with one-job linked Redstone Controllers. Their fixed mode menu stays visible above the scrolling form and explains every job.
- Resolve shared-target controller input once per tick: OR playback, maximum requested volume, and deterministic pulse priority with duplicate commands coalesced.
- Preserve manual volume with transient controller overrides; release contributions on removal, unload, retarget and permission revocation. Handle proxy reloads and unloaded output snapshots without loading chunks.
- Redrew player transport icons at 18×18 for clearer shuffle, repeat and restart symbols.
- Updated the guide and migration documentation; added cross-version conflict, persistence, permissions and lifecycle regressions plus native mode-picker interaction coverage.

- Initialize fresh speaker networks before immediate ID assignment, so a controller can link before the first block tick.
- Prevent transport stop and decoder completion from scheduling duplicate OpenAL cleanup, which could delete a source reused by rapid restart.

- Add searchable playlist choices with track counts and a numbered queue showing each entry source.
- Consolidate Loop into player-bar Repeat, preserve repeat across state packets, and let requests/manual Next interrupt Track repeat correctly.
- Correct the restart symbol and explain that it returns the current sound to 0:00.
- Group directional sound controls and add an eight-second world preview using playback attenuation settings.
- Save controller configuration on close and synchronize speaker network/directional settings when reopening.
- Repaginate the guide to fit the native book layout. Generate dedicated controller casing and retain generated book/circuit sprites at 64×64 with transparency.

- Apply slider changes while dragging. Volume and directional updates preserve active audio decoders instead of repeatedly stopping and recreating playback; range changes reconcile only listeners entering/leaving the audible area.

- Reject hexadecimal IPv4-mapped IPv6 stream addresses when their embedded IPv4 address is private, loopback or otherwise blocked.
- Preserve queued playback continuation through track removal, replacement and reordering.
- Send authoritative speaker settings to client replicas, including display names and controller volume, without restarting playback.
- Expand ComputerCraft and public Java automation APIs with owner-library discovery, saved playlist playback, queue editing and audio settings. Enforce anonymous automation permissions and recording ownership at the public API boundary.
- Run real ComputerCraft Lua acceptance on all four supported loaders, including events, protected access, detach/reattach and computer reboot.
