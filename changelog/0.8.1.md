# Simply Speakers 0.8.1

## Changed

- Migrated the speaker and proxy-speaker interfaces to OpenUI MC across Fabric 1.20.1, Forge 1.20.1, Fabric 1.21.1, NeoForge 1.21.1, and NeoForge 26.1.2.
- Added responsive themed window shells, scrolling settings, flexible audio lists, filename marquees, and wider controls consistently across supported loaders.
- Declared OpenUI MC 0.0.5 as a required runtime dependency.

## Fixed

- Disabled text shadows by default throughout the migrated interfaces.
- Prevented focused tab bars from being filled entirely with the theme accent color.
- Prevented audio-row action buttons from shrinking after scrolling.
- Expanded setting tooltips to activate from their labels and rows, not only from slider handles.
- Kept long filenames and status text constrained to their available layout space.

## Development

- Added cross-version OpenUI artifact bootstrapping to CI and release builds.
- Extended live client-join testing to every supported loader target.
