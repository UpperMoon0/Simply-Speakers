# 0.10.2

- Add standalone requested-generation ports: Forge 1.12.2, Fabric/Forge 1.16.5, and Fabric/NeoForge 26.2.
- Retain full speaker playback, portable speakers, shared networks, redstone controls, permission/ownership enforcement, bounded audio uploads, playlists and OpenUI screens on native generation APIs.
- Lower legacy runtime and regression sources to Java 8; use Java 25 and the native graphics abstraction for 26.2.
- Require the matching requested-generation OpenUI MC 0.0.15 and PacketWeave 0.1.4 dependencies. Existing targets retain their existing minimum versions.
- Use gold and quartz instead of unavailable copper and amethyst in the 1.12.2/1.16.5 audio circuit recipe.
