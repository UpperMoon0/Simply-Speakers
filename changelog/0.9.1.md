# Simply Speakers 0.9.1

- Require PacketWeave 0.1.2 on clients and servers across all five loader targets.
- Move upload creation, writes and cleanup off the game thread into a bounded receiver.
- Replace the fixed-delay upload loop with indexed chunks and disk-write receipts.
- Cancel disconnected, disabled, rejected, timed-out and shutdown uploads safely.
- Reuse PacketWeave for bounded file sending and remove duplicated native chunking/writing.
- Add a two-player, real-packet 60 MiB WAV upload probe with baseline/during/recovery server tick statistics.
- Update clients and server together: the upload wire protocol changed.

- Coordinate cancellation and shutdown with an explicit terminal upload commit, keeping slow validation and publication off the game thread.
- Keep failed uploads unpublished and let PacketWeave retry partial-file cleanup.
- Dispatch downloads in bounded 16-packet batches instead of waiting for one game-thread turn per chunk.
