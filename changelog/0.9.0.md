# Simply Speakers 0.9.0

## Added

- Portable Speaker: a non-stackable carried audio source using the supplied
  original sprite. Use it to open the normal Library, Playlist, Queue and
  Settings player; playback follows the carrier and is spatially audible to
  nearby players.
- Portable transport, upload/library/URL support, saved playlists, queues,
  repeat/shuffle, range/volume/dropoff, directional sound and network access
  controls reuse the existing authoritative speaker services.
- Server-assigned item identity, persistent state, inventory-possession packet
  checks, duplicate identity isolation and cleanup on removal, transfer,
  logout, death and dimension changes.
- Inventory recipe, creative entry, in-game guide and portable behavior guide.
- Focused identity, lifecycle, permissions, codec and moving-audio verification.

## Changed

- Mobile sources carry authoritative world poses independently of normal entity
  tracking, with client interpolation and cleanup of stopped sources.
- Legacy track-selection messages now apply the same recording ownership and
  direct-URL validation as the normal player.
- Portable items have no physical comparator, redstone sides or ComputerCraft
  peripheral. These remain available through placed blocks on linked networks.
- Clients and servers should update together for the portable packet extensions.
