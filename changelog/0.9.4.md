# Simply Speakers 0.9.4

- Allow optional Sable 2.0.6 on Minecraft 1.21.1 (Fabric and NeoForge), retaining support for 2.0.5 and allowing later 2.x versions through the existing Companion 1.6.0 API.
- Default local Sable development runtimes to 2.0.6; override with `-Psable_version=<version>` for later builds.
- Add regression tests for both loader version ranges, optional installation, and the Sable 3 compatibility boundary.
